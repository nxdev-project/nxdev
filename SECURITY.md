# Security Policy

## Reporting Security Issues

The NXDev team takes the security and integrity of homebrew tooling seriously.

If you discover a security vulnerability or critical flaw in NXDev, please report it privately to the maintainers rather than opening a public GitHub issue.

## Safe Homebrew Execution

NXDev is an educational and homebrew development framework. Always ensure you are executing homebrew applications only on devices you own or have explicit authorization to test on.
